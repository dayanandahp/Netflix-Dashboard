# 🎬 Netflix Dashboard (Power BI)

This Power BI project analyzes Netflix data to uncover insights about content trends, genres, ratings, and release patterns.

## 📊 Key Features
- Data cleaning and transformation using Power Query.
- Interactive Power BI dashboard for visualizing:
  - Movie vs. TV Show distribution
  - Top genres and countries
  - Yearly content growth trends
  - Ratings breakdown
- Built-in filters for exploring different categories.

## 🧠 Tools Used
- **Power BI** – for data modeling and dashboard creation  
- **Excel / CSV** – as the data source  
- **Power Query** – for data cleaning and transformation  

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it in Power BI Desktop.
3. Explore the dashboard interactively.
